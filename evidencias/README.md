# Evidencias del proyecto Solana Sales Registry

## Descripción

Esta carpeta contiene las evidencias técnicas del desarrollo del proyecto Solana Sales Registry, realizado como parte del Solana Engineering Track: Advanced.

## Evidencias de desarrollo

1. Compilación exitosa del programa Rust en Solana Playground.
2. Despliegue del programa en Solana Devnet.
3. Exportación del archivo IDL.
4. Generación y validación del cliente TypeScript.
5. Ejecución del frontend desarrollado con React y Vite.
6. Conexión de la wallet Solflare a la aplicación.
